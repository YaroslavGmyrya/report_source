\subsection{Seaborn}
Библиотека для визуализации данных в Python, построенная на основе Matplotlib. Она предоставляет высокоуровневый, простой 
интерфейс для создания привлекательных, информативных и сложных статистических графиков с минимальным количеством кода. 
Seaborn тесно интегрирована с библиотекой Pandas для удобной работы с табличными данными.
