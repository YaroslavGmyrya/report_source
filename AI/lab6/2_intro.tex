\chapter{Введение}
\label{ch:intro}

\section{Цель}  

Разработка единого пайплайна для решения
задачи регрессии


\section{Задачи} 

\begin{enumerate} 
\item реализовать каонвейер для выполнения всех стадий обработки данных
при решении задачи одномерной регрессии;
\item получение теоретических представлений о задаче регресии;
\item получение навыков использования пайплайна при решении задачи
машинного обучения;
\item получение навыков рефакторинга кода в задачах машинного обучения.
\end{enumerate}
