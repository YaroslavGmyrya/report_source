\chapter{Введение}

\section{Цель}  

Изучение программных средств для
организации рабочего места специалиста по анализу данных и машинному
обучению.


\section{Задачи}

\begin{enumerate}
    \item Получение программного доступа к данным, содержащимся в источниках различного типа;
    \item Выполнение предварительного анализа данных и получение обобщенных характеристик наборов данных;
    \item Исследование простых методов визуализации данных;
    \item Изучение основных библиотек Python для работы с данными.

\end{enumerate}
