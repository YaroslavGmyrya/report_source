\section{Введение}

Командная строка предназначена для «прямого» управления системой без использования
графической оболочки, а терминал – оболочка для командной строки в ОС с графическим
интерфейсом.

\section{Цель}  

\begin{enumerate}
    \item Изучить способы вызова командной строки.
    \item Познакомиться с терминалом.
    \item Научиться взаимодействовать с командной сторкой и изучить базовые команды.
\end{enumerate}
