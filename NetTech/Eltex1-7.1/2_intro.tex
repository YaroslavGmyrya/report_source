\section{Введение}
Команда nslookup — инструмент сетевого администрирования для запросов в доменной
системе имен (DNS) с целью получения доменного имени, IP-адреса или другой информации из
записей DNS.
 
\section{Цель}  

\begin{enumerate}
    \item Изучить синтаксис команды nslookup.
    \item Провести обратный поиск DNS с использованием команды nslookup.
    \item Освоить использование интерактивного режима в команде nslookup.
    \item Анализировать результаты команды nslookup и извлекать необходимую информацию.
\end{enumerate}
