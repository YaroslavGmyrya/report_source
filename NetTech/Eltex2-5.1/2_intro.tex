\chapter{Введение}

\section{Цель}  

Произвести настройку маршрутизаторов. Настроить
суммарный маршрут и плавающий статический маршрут для организации сетевой
связности между маршрутизаторов.
\section{Задачи}

\begin{enumerate}
\item Интерфейс Gi1/0/1 маршрутизатора R1 соединить с интерфейсом Gi1/0/1
маршрутизатора R2.
\item Компьютер VPC1 подключить к интерфейсу Gi1/0/2 маршрутизатора R1.
\item Компьютер VPC2 подключить к интерфейсу Gi1/0/3 маршрутизатора R1.
\item Интерфейс Gi1/0/4 маршрутизатора R1 соединить с интерфейсом Gi1/0/2
маршрутизатора R3.
\item Компьютер VPC3 подключить к интерфейсу Gi1/0/2 маршрутизатора R2.
\item Компьютер VPC4 подключить к интерфейсу Gi1/0/3 маршрутизатора R2.
\item Интерфейс Gi1/0/4 маршрутизатора R2 соединить с интерфейсом Gi1/0/1
маршрутизатора R3.
\item На маршрутизаторе R1 настроить имя «Router_left».
\item На маршрутизаторе R2 настроить имя «Router_right».
\item На маршрутизаторе R3 настроить имя «Router_down».
\item На интерфейс Gi1/0/1 маршрутизатора R1 задать адрес 192.168.100.1/30.
\item На интерфейс Gi1/0/1 маршрутизатора R2 задать адрес 192.168.100.2/30.
\item На интерфейс Gi1/0/2 маршрутизатора R1 задать адрес 10.10.0.1/24.
\item На интерфейс Gi1/0/3 маршрутизатора R1 задать адрес 10.10.1.1/24.
\item На интерфейс Gi1/0/4 маршрутизатора R1 задать адрес 10.10.100.1/24.
–\item На интерфейс Gi1/0/2 маршрутизатора R2 задать адрес 10.10.10.1/24.
\item На интерфейс Gi1/0/3 маршрутизатора R2 задать адрес 10.10.11.1/24.
\item На интерфейс Gi1/0/4 маршрутизатора R2 задать адрес 172.16.200.2/24.
\item На компьютере VPC1 настроить IP адрес 10.10.0.10/24 и шлюз по умолчанию.
–\item На компьютере VPC2 настроить IP адрес 10.10.1.20/24 и шлюз по умолчанию.
\item На интерфейс Gi1/0/1 маршрутизатора R3 задать адрес 172.16.200.1/30
\item На интерфейс Gi1/0/2 маршрутизатора R3 задать адрес 10.10.100.2/30.
\item На компьютере VPC3 настроить IP адрес 10.10.10.10/24 и шлюз по
умолчанию.
\item На компьютере VPC4 настроить IP адрес 10.10.11.20/24 и шлюз по
умолчанию.
\item Настроить суммарный маршрут 10.10.0.0/23 192.168.100.2 на
маршрутизаторе R2.
\item Настроить суммарный маршрут 10.10.10.0/23 192.168.100.1 на
маршрутизаторе R1.
\item Настроить на маршрутизаторе R1 и R2 плавающий маршрут с префиксом
10 до маршрутизатора R3.
\item На маршрутизаторе R3 настроить маршруты к маршрутизаторам R1 и R2.
\item Проверить сетевую связность VPC1 и VPC4 командами ping и tracert.
\item Отключить соединение между маршрутизаторами R1 и R2 и проверить
сетевую связность между VPC1 и VPC4 ping и tracert.
\end{enumerate}
