\chapter{Введение}

\section{Цель}  

Произвести настройку маршрутизаторов. Настроить
статические маршруты для организации сетевой связности между
маршрутизаторами.
\section{Задачи}

\begin{enumerate}
\item Интерфейс Gi1/0/1 маршрутизатора R1 соединить с интерфейсом Gi1/0/1
маршрутизатора R2.
\item Компьютер VPC1 подключить к интерфейсу Gi1/0/2 маршрутизатора R1.
\item Компьютер VPC2 подключить к интерфейсу Gi1/0/3 маршрутизатора R1.
\item Компьютер VPC3 подключить к интерфейсу Gi1/0/4 маршрутизатора R1.
\item Компьютер VPC4 подключить к интерфейсу Gi1/0/2 маршрутизатора R2.
\item Компьютер VPC5 подключить к интерфейсу Gi1/0/3 маршрутизатора R2.
\item Компьютер VPC6 подключить к интерфейсу Gi1/0/4 маршрутизатора R2.
\item На маршрутизаторе R1 настроить имя «Rout r\_l\ ft».
\item На маршрутизаторе R2 настроить имя «Rout\ r\_right».
\item На интерфейс Gi1/0/1 маршрутизатора R1 задать адрес 192.168.100.1/30.
\item На интерфейс Gi1/0/1 маршрутизатора R2 задать адрес 192.168.100.2/30.
\item На интерфейс Gi1/0/2 маршрутизатора R1 задать адрес 172.16.10.1/24.
\item На интерфейс Gi1/0/3 маршрутизатора R1 задать адрес 172.16.20.1/24.
\item На интерфейс Gi1/0/4 маршрутизатора R1 задать адрес 172.16.30.1/24.
\item Посмотреть информацию о маршрутах в таблице маршрутизации
маршрутизатора R1.
\item На интерфейс Gi1/0/2 маршрутизатора R2 задать адрес 10.10.40.1/24.
\item На интерфейс Gi1/0/3 маршрутизатора R2 задать адрес 10.10.50.1/24.
\item На интерфейс Gi1/0/4 маршрутизатора R2 задать адрес 10.10.60.1/24.
\item Посмотреть информацию о маршрутах в таблице маршрутизации
маршрутизатора R2.
\item На компьютере VPC1 настроить IP адрес 172.16.10.10/24 и шлюз по
умолчанию.
\item На компьютере VPC2 настроить IP адрес 172.16.20.20/24 и шлюз по
умолчанию.
\item На компьютере VPC3 настроить IP адрес 172.16.30.30/24 и шлюз по
умолчанию.
\item На компьютере VPC4 настроить IP адрес 10.10.40.10/24 и шлюз по
умолчанию.
\item На компьютере VPC5 настроить IP адрес 10.10.50.20/24 и шлюз по
умолчанию.
\item На компьютере VPC6 настроить IP адрес 10.10.60.30/24 и шлюз по
умолчанию.
\item На маршрутизаторе R1 создать маршрут по умолчанию в сторону
маршрутизатора R2.
\item На маршрутизаторе R2 создать маршрут по умолчанию в сторону
маршрутизатора R1.
\item Проверить сетевую связность между подсетями.
\item Удаление статического маршрута по умолчанию на маршрутизаторе R1.
\item Создание статических маршрутов до сетей 10.10.40.0/24, 10.10.50.0/24,
10.10.60.0/24
\item Проверка сетевой связности
\item Удалить на маршрутизаторе R1 статический маршрут до сети 10.10.40.0/24
\item Проверить сетевую связность между VPC3 и VPC4, VPC3 и VPC5
\end{enumerate}
